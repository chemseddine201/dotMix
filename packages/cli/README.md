# @dotmix/cli

The `mix` command for dotMix: create, develop, type-check, build, preview and test `.mix` / `.tix` projects.

Part of [dotMix](https://github.com/chemseddine201/dotMix), a compiler-native web framework with no virtual DOM.

## Usage

```bash
# Create a project (TypeScript + SCSS)
npx -p @dotmix/cli mix create my-app --ts --scss

# Or add the CLI to an existing project
npm install -D @dotmix/cli
npx mix dev
```

All commands and flags: [docs/CLI.md](https://github.com/chemseddine201/dotMix/blob/master/docs/CLI.md).

See the [main README](https://github.com/chemseddine201/dotMix#readme) for documentation.
