# Agent Handoff

## Assignment

Run the initialization audit only, using `agent/INITIALIZATION_AGENT_TASK.md`.

## Scope boundary

Allowed: read-only inspection and creation of the nine requested Markdown reports.

Forbidden: implementation, dependency installation, source/spec edits, file deletion, file moves, or Showcase changes.

## Required stop

After reports are complete, stop and wait for explicit approval from the Human Architecture Authority.

## Approval phrase

Implementation is not authorized by this handoff. The owner must explicitly state which phase is approved before the agent begins coding.
